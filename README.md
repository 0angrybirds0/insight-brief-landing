# Insight Brief 태블릿 우선 랜딩 페이지 v2

정보 콘텐츠 제공자가 방문자의 닉네임과 연락 수단 하나(이메일, 전화번호, 인스타그램 아이디)를 받을 수 있도록 만든 반응형 단일 랜딩 페이지입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 로컬 서버가 필요하면 다음 명령을 실행하세요.

```bash
python3 -m http.server 8000
```

그 후 `http://localhost:8000`으로 접속합니다.

## 현재 범위

- 오프화이트·블랙 기반의 밝고 미니멀한 디자인
- 안드로이드 태블릿 세로·가로 화면 우선 최적화
- 고정형 헤더와 태블릿 전용 간격·타이포그래피
- 연락 방법에 따른 입력 필드 자동 변경
- 닉네임·연락처·개인정보 동의 유효성 검사
- 시연용 완료 메시지
- 서버 저장 기능은 아직 연결하지 않음
